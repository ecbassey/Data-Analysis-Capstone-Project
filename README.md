# Data-Analysis-Capstone-Project

## OPTION 1: Airline Performance & Delay Intelligence System



[Streamlit: Project Link](https://ecbassey-data-analysis-capstone-project-app-37dptu.streamlit.app/)

### Problem Statement
This project aims to identify the most reliable airlines, peak delay periods, major airport bottlenecks, and key factors driving delays, while uncovering geographic patterns to support data-driven insights and operational improvements. 

The goal of the Airline Delay Intelligence System is to provide a dynamic, data-driven platform that transforms airline operational data into actionable insights for monitoring performance, identifying bottlenecks, and improving decision-making across airlines and airports.


### Tools/Skills use:
- Data ingestion: scraping, CSV
- Data Transformation: BigQuery
- Data Storage: SQL
- Data cleaning & analysis: Python / Pandas
- Software design: OOP
- Visualization: matplotlib / seaborn / GeoPandas


### Insights and Solutions:
This project aims to transform raw flight data into meaningful insights that help airlines, airports, and stakeholders better understand and manage delays and cancellations. This project aims to help airline stakeholders answer key questions such as:
- How reliable is my airline
- What month has the highest delays (months, seasons, etc.)
- Did the industry recover after COVID
- Which airports are bottlenecks
- What factors most influence delays
- What are the delay and cancellation patterns across different airlines


### Business and community impact of this anlysis:
#### Airline Companies
Gain insights into delay patterns, operational inefficiencies, and performance trends, helping them improve scheduling, reduce delays, and optimize resources.

#### Airport Authorities
Identify congestion points, peak traffic times, and bottlenecks to improve airport operations and capacity planning.

#### Government & Aviation Regulators
Monitor industry performance, assess the impact of disruptions (like COVID-19), and make informed policy or infrastructure decisions.
